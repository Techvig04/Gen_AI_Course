# 🤖 Gemini AI Chatbot

A simple AI chatbot built using **Google Gemini API**, **LangChain**, and **Python**. The project was developed and tested using **Google Colab**.

## 📌 Project Description

This project demonstrates the integration of Google's Gemini Generative AI model with LangChain to create a simple interactive chatbot.

The chatbot accepts a question from the user and generates an AI-powered response using the Gemini model.

## 🚀 Features

* Simple AI chatbot
* Google Gemini API integration
* LangChain integration
* Interactive user input
* Prompt template
* AI-generated responses
* Secure API key handling using Google Colab Secrets

## 🛠️ Technologies Used

## 🔑 API Key Setup

This project requires a Gemini API key.

The API key is stored securely using **Google Colab Secrets**.

Create a secret with the following name:

```text
Gemini_API_Key
```

**Do not upload your actual API key to GitHub.**

## ▶️ How to Run

### Using Google Colab

1. Open `Vighnesh_116.ipynb` in Google Colab.
2. Add your Gemini API key to Colab Secrets.
3. Make sure the secret name is:

```text
Gemini_API_Key
```

4. Run the notebook cells.
5. Enter your question when prompted.
6. The chatbot will generate a response.
